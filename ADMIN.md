# Инструкция владельца сайта (админка записи)

## 1. Как открыть админку
* Адрес: **https://beknurssss25-bit.github.io/informatika-kursy/admin.html** — на сайте ссылки на неё нет, добавьте в закладки. Поисковикам страница закрыта (`noindex`).
* Начальный PIN: **2580**. Сразу смените его (раздел «Сменить PIN» внизу страницы).
* Что видно: календарь на 30 дней (часы 10:00–19:00, воскресенье — выходной, как на сайте). Цвета часов: зелёный — свободно, жёлтый — записан ученик, красный — закрыто вами, серый — прошло.

## 2. Занять / закрыть время
* Выберите дату → нажмите **зелёный (свободный) час**. Откроется окно с двумя вариантами:
  * **Занято учеником** — по желанию имя, телефон, заметка (тариф, что изучает). На сайте час показывается как «занято».
  * **Нет занятий** — причина: *учитель занят / выходной / другое* (+ пояснение). На сайте тоже «занято».
* Нажмите на занятый вами час (красный — «нет занятий», фиолетовый с именем — «занято учеником») → можно изменить данные или **«Освободить время»**. Строка в списке «Ближайшие записи» для внесённых вручную часов тоже открывает это окно.
* Жёлтые часы — записи с сайта. Их изменить нельзя (при нажатии покажется тариф).
* **«Закрыть весь день»** и **«Закрыть часы…»** (например, с 14:00 до 18:00): выбираете причину; закрываются только свободные часы. **«Открыть день»** открывает все часы «нет занятий»; ученики (с сайта и внесённые вручную) остаются.
* Календарь: точка жёлтая — есть записи/«занято учеником», красная — есть часы «нет занятий».
* **Где хранятся данные (важно):** имя, телефон, заметка и пояснения сохраняются **только в браузере, где вы их ввели** (localStorage). На другом телефоне/компьютере, в другом браузере или после очистки данных браузера они не видны — там останется просто «занято» или причина. Это сделано намеренно: общее хранилище открыто для всех, поэтому имена и телефоны туда не попадают. Для важных данных ведите отдельную запись.
* Что уходит в общее хранилище и на сайт: только отметка вида `12-adm-student` («занято учеником»), `12-adm-busy` (учитель занят), `12-adm-off` (выходной), `12-adm-blocked` (другое; так же, как писала прошлая версия админки). Публичный календарь считает любой такой час занятым.
* Записи с сайта в списке — только дата, время и тариф: **имя и телефон ученика в общем хранилище не сохраняются**, они приходят вам в WhatsApp.

## 3. Сменить PIN
Админка → внизу «Сменить PIN» → текущий PIN, новый (не короче 4 символов, лучше 6+) дважды.
Новый PIN хранится в виде хэша в том же общем хранилище, поэтому действует на всех ваших устройствах.

**Честно о защите:** сайт статический, хранилище открытое. PIN — лёгкая защита, которая прячет админку от случайных людей. Технически подкованный человек может обойти PIN (хэш виден в коде / хранилище), перебрать короткий PIN или записать в хранилище свои значения напрямую (так же, как это делает публичный календарь). Ничего секретного (телефоны, оплаты) в хранилище нет, поэтому худшее, что возможно, — лишние закрытые часы или лишние записи.

**Забыли PIN:** откройте `admin.html` на компьютере → F12 → Console → `adminHash('новый PIN')` → скопируйте результат → в GitHub откройте `js/admin.js`, замените значение в строке `var PIN_HASH='…'` → Commit changes. Сохранённый ранее в хранилище PIN после этого перестаёт действовать.

GitHub → репозиторий → файл → ✎ (Edit) → правка → **Commit changes**. Сайт обновится примерно через минуту (при необходимости обновите страницу с Ctrl+F5).

**Цены** (меняйте везде, иначе будут расхождения):

* `js/app.js`, строка `var PLANS=…` — отсюда цена попадает в подтверждение записи и сообщение в WhatsApp. Файл `app.js` содержит и логику записи — меняйте только текст цен.

## 5. Передать репозиторий другому человеку
1. **Дать доступ:** GitHub → репозиторий `informatika-kursy` → Settings → Collaborators → Add people (по логину/почте). Новый человек сможет править файлы.
2. **Передать полностью:** Settings → General → Danger Zone → *Transfer ownership* → логин нового владельца. Адрес сайта изменится на `https://НОВЫЙ-ЛОГИН.github.io/informatika-kursy/`; ссылки/QR/визитки со старым адресом нужно обновить. (Старый адрес GitHub обычно перенаправляет не всегда — проверьте.)
3. Убедитесь, что Pages включены: Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
4. Передайте новому владельцу: адрес админки, PIN (пусть сразу сменит), этот файл (`ADMIN.md`).
5. Записи хранятся во внешнем бесплатном сервисе keyvalue.immanuel.co (ключ приложения — `CFG.appKey` в `js/app.js` и `js/admin.js`, они должны совпадать). Если сервис пропадёт, календарь покажет предупреждение, а записи останутся только на устройствах учеников — тогда нужен другой бэкенд.
