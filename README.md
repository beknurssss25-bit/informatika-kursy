# Курсы информатики — версия с 3D-героем (черновик, не задеплоено)

Статический сайт (HTML/CSS/JS), без сборки, без внешних CDN и без внешних 3D-моделей/картинок/платных сервисов — работает на GitHub Pages как есть.
Весь контент прежний: тарифы 25 000 / 50 000 / 100 000 ₸ (1 / 2 / 5 месяцев), общий календарь записи, телефон 8 705 646 83 07, адрес «Школа 250, кабинет 3, 3 этаж». Весь текст на русском.

## Что нового
* **Scroll-driven 3D hero** (`js/scene.js`, `js/screen.js`): ноутбук целиком собран в Three.js из примитивов (скруглённые боксы, InstancedMesh-клавиатура, цилиндр-шарнир, экран с canvas-текстурой).
  Ноутбук **стартует закрытым**; самый небольшой скролл (первые ~9% героя) полностью открывает крышку. Дальше камера облетает и «влетает» в экран, и на экране по скроллу идёт последовательность: **редактор кода** — программа печатается построчно (`# Моя первая программа`, `print("Привет, мир!")`, цикл, сумма) → кнопка **«▶ Запустить»** → в панели **вывода** появляется результат (`Привет, мир!`, `Шаг 1`, `Шаг 2`, `2 + 3 = 5`, `✓ Готово`) → вкладки **О курсах → Тарифы → Запись** → стенд сразу «отпускается» в обычные секции (без пустой затемнённой паузы).
* Длина героя: **400vh** на десктопе, **380vh** на мобильных (≤620px) — это ~300vh прокрутки; таймлайн в `js/scene.js` (комментарий над `tl.to…`), раскладка в `css/story.css`.
* **Дополнения (extras)**: `css/extras.css` + `js/extras.js` — прогресс-бар чтения в навигации, плавающая кнопка «Записаться на занятие» (после героя, прячется у блока записи), свечение за курсором и лёгкий наклон ноутбука от мыши (только мышь, не тач), анимированные счётчики (только факты со страницы: 8 модулей, 40 занятий, 60 минут, 3 тарифа), печатающийся терминал «Что будет на занятиях», тариф на 2 месяца с меткой «Популярный» и подсветкой карточек при наведении, плавные аккордеоны программы/FAQ, карточки отзывов — явно помечены «Пример текста» (не реальные отзывы).
* Частицы (шейдер, дрейф на GPU), плавающие code-глифы, свечение/подсветка клавиш, тёмная тема с фиолетово-бирюзовым градиентом (`css/theme.css`).
* Плавный скролл — Lenis (на тач-устройствах нативный), анимация по скроллу — GSAP + ScrollTrigger.
* **Производительность**: на мобильных/слабых устройствах (`<768px`, `pointer:coarse`, ≤4 ядер/≤4 ГБ) — pixel ratio ≤1.25, 260 частиц, текстура экрана 1024×640 @18 fps, без MSAA; на десктопе — dpr ≤1.75, 1400 частиц, 1600×1000 @30 fps. Если FPS падает, качество автоматически снижается (dpr, частицы, глифы). Рендер останавливается, когда hero не на экране.
* **Фолбэк**: нет WebGL / `prefers-reduced-motion` / ошибка загрузки модуля / потеря контекста → показывается статичный hero (текст + оригинальная иллюстрация `images/hero.svg`), всё остальное работает так же. Принудительно: `?3d=off`. Качество вручную: `?q=low` / `?q=high`.
* Календарь записи (`js/app.js`) **не менялся** (побайтово идентичен оригиналу); стили календаря лишь перекрашены под тёмную тему (`css/theme.css`), разметка и классы те же.

## Структура
```
index.html            разметка (hero = .story > .stage > canvas + текст)
css/style.css         оригинальные стили (без изменений)
css/theme.css         тёмная тема поверх style.css
css/story.css         3D-hero, мобильная раскладка, статический фолбэк
js/app.js             оригинальная логика: меню, календарь, запись (без изменений)
js/scene.js           Three.js сцена + GSAP-таймлайн + Lenis
js/screen.js          рисует содержимое экрана ноутбука на 2D canvas (редактор → запуск → вывод → слайды)
js/extras.js          прогресс, плавающая кнопка, счётчики, терминал, аккордеоны (календарь не затрагивает)
css/extras.css        стили этих дополнений
js/vendor/            three.min.js (r0.186, tree-shaken), gsap, ScrollTrigger, lenis (+ лицензии)
tests/run.py          Playwright-тест (1280 и 390), скриншоты в shots/
```
Хранилище записи: как и раньше — публичный `keyvalue.immanuel.co` (см. `CFG` в `js/app.js`); в тестах запросы к нему подменяются, живые данные не затрагиваются.

## Локальный запуск
`python3 -m http.server 8777` в этой папке → http://127.0.0.1:8777/ (ES-модули не работают с `file://` — тогда автоматически включится статичный hero).

## Пересборка three.min.js
`npm i three` → entry с `export {…} from 'three'` + `RoundedBoxGeometry`, `RoomEnvironment` → `esbuild --bundle --minify --format=esm`.
