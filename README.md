# Курсы информатики — сайт

Статический сайт (HTML/CSS/JS, без сборки и без внешних CDN). Шрифты Onest и JetBrains Mono (SIL OFL) лежат в `fonts/`.

**Онлайн-запись** хранит занятые слоты в бесплатном публичном key-value сервисе `keyvalue.immanuel.co` (по одному ключу на день).
Это демонстрационное решение: данные публичны, любой, знающий ключ приложения, может их прочитать или изменить.
Для продакшена нужен собственный бэкенд с авторизацией и админ-панелью. Ключ приложения задаётся в `js/app.js` (`CFG.appKey`).

Контакты и адрес правятся прямо в `index.html`.
